## 1. 防抖 debounce
**题目**：事件停止触发 delay 毫秒后才执行一次，用于搜索输入、窗口 resize。
```js
function debounce(fn, delay = 300) {
  let timer = null;                        // 闭包保存定时器
  return function (...args) {
    clearTimeout(timer);                   // 新触发就重置计时
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```
**考察点**：闭包、this 与参数透传、定时器清理；进阶追问"首次立即执行"用 immediate 参数。　**易错点**：返回箭头函数导致 this 丢失；忘记 clearTimeout 反变成节流；timer 放外层而不是闭包内。
## 2. 节流 throttle
**题目**：连续触发时每 interval 毫秒最多执行一次，用于滚动、拖拽。
```js
function throttle(fn, interval = 300) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last < interval) return;
    last = now;
    fn.apply(this, args);
  };
}
```
**考察点**：时间戳判断、闭包；与防抖的本质区别是节流保证执行频率，防抖只认最后一次。　**易错点**：比较符号写反；首调用被吞（初始化 last = 0 即可立即执行）；忘记透传 this。
## 3. 深拷贝（含循环引用）
**题目**：递归拷贝对象，处理 Date/RegExp/数组，用 WeakMap 解决循环引用。
```js
function deepClone(target, map = new WeakMap()) {
  if (target === null || typeof target !== 'object') return target;
  if (map.has(target)) return map.get(target);            // 循环引用直接返回已拷贝对象
  if (target instanceof Date) return new Date(target);
  if (target instanceof RegExp) return new RegExp(target);
  const clone = Array.isArray(target) ? [] : Object.create(Object.getPrototypeOf(target));
  map.set(target, clone);                                 // 先存再递归，否则栈溢出
  Reflect.ownKeys(target).forEach((key) => { clone[key] = deepClone(target[key], map); });
  return clone;
}
```
**考察点**：递归、WeakMap、原型链、Symbol 键（Reflect.ownKeys）。　**易错点**：先递归后 set 导致循环引用爆栈；JSON 方案丢函数/Date/undefined；Map/Set 需单独处理。
## 4. 手写 Promise 核心（then 链式）
**题目**：实现 state/value/callbacks 三要素，then 返回新 Promise 并支持值穿透。
```js
class MyPromise {
  constructor(executor) {
    this.state = 'pending'; this.value = undefined; this.callbacks = [];
    const settle = (state, value) => {
      if (this.state !== 'pending') return;               // 状态不可逆
      this.state = state; this.value = value;
      this.callbacks.splice(0).forEach((cb) => this.run(cb));
    };
    try { executor((v) => settle('fulfilled', v), (r) => settle('rejected', r)); } catch (e) { settle('rejected', e); }
  }
  run(cb) {
    if (this.state === 'pending') return this.callbacks.push(cb);
    queueMicrotask(() => {                                // 真实 Promise 回调是微任务
      const handler = this.state === 'fulfilled' ? cb.onFulfilled : cb.onRejected;
      if (typeof handler !== 'function') return (this.state === 'fulfilled' ? cb.resolve : cb.reject)(this.value);
      try {
        const result = handler(this.value);
        result instanceof MyPromise ? result.then(cb.resolve, cb.reject) : cb.resolve(result);
      } catch (e) { cb.reject(e); }
    });
  }
  then(onFulfilled, onRejected) {
    return new MyPromise((resolve, reject) => this.run({ onFulfilled, onRejected, resolve, reject }));
  }
}
```
**考察点**：状态机、发布订阅、then 返回新 Promise、异常捕获、值穿透。　**易错点**：不用微任务导致时序错；then 里 return this 无法链式；忘记捕获 executor 抛错。
## 5. 手写 Promise.all / allSettled / race
**题目**：all 全成功才成功、allSettled 等全部结束、race 取最先结束。
```js
const promiseAll = (list) => new Promise((resolve, reject) => {
  const arr = Array.from(list), res = new Array(arr.length);
  let count = 0;
  if (!arr.length) return resolve(res);
  arr.forEach((p, i) => Promise.resolve(p).then((v) => {
    res[i] = v;                                           // 按原顺序放结果
    if (++count === arr.length) resolve(res);
  }, reject));
});
const promiseAllSettled = (list) => Promise.all(Array.from(list).map((p) =>
  Promise.resolve(p).then((value) => ({ status: 'fulfilled', value }), (reason) => ({ status: 'rejected', reason }))));
const promiseRace = (list) => new Promise((resolve, reject) =>
  Array.from(list).forEach((p) => Promise.resolve(p).then(resolve, reject)));
```
**考察点**：并发计数、结果保序、Promise.resolve 兼容非 Promise 值、空数组边界。　**易错点**：用 Promise.all 实现 all 等于没写；count 判断错导致不 resolve；race 空数组永远不 settle。
## 6. 手写 call / apply / bind
**题目**：改变函数执行时的 this，bind 还要支持 new 调用与参数预设。
```js
Function.prototype.myCall = function (ctx, ...args) {
  ctx = ctx == null ? globalThis : Object(ctx);           // 非严格模式下 null 指向全局
  const key = Symbol('fn'); ctx[key] = this;
  const result = ctx[key](...args); delete ctx[key];      // 用完删除，防污染
  return result;
};
Function.prototype.myApply = function (ctx, args = []) { return this.myCall(ctx, ...args); };
Function.prototype.myBind = function (ctx, ...bound) {
  const fn = this;
  function Fn(...args) { return fn.apply(this instanceof Fn ? this : ctx, [...bound, ...args]); }
  Fn.prototype = Object.create(fn.prototype);
  return Fn;
};
```
**考察点**：this 绑定、Symbol 防属性覆盖、bind 与 new 共存（new 时忽略绑定的 this）。　**易错点**：用箭头函数实现 bind（没有 this 和 prototype）；忘记 delete；bind 后丢原型链。
## 7. 手写 new

```js
function myNew(Ctor, ...args) {
  if (typeof Ctor !== 'function') throw new TypeError('Ctor is not a function');
  const obj = Object.create(Ctor.prototype);
  const result = Ctor.apply(obj, args);

```
**考察点**：原型链、apply、构造函数返回对象时覆盖实例、返回原始值时忽略。　**易错点**：忘判返回值为对象；用 `{}` 而不是 Object.create 导致原型错；箭头函数不能被 new。
## 8. 手写 instanceof
**题目**：沿原型链向上查找，判断构造函数的 prototype 是否出现在链上。
```js
function myInstanceof(obj, Ctor) {
  if (typeof Ctor !== 'function') throw new TypeError('Right-hand side is not callable');
  let proto = obj == null ? null : Object.getPrototypeOf(obj);
  while (proto) {
    if (proto === Ctor.prototype) return true;
    proto = Object.getPrototypeOf(proto);
  }
  return false;
}
```
**考察点**：原型链遍历、基本类型返回 false、proto 为 null 时终止。　**易错点**：混淆 `__proto__` 与 `prototype`；对原始类型抛异常（原生返回 false）。
## 9. 柯里化 curry
**题目**：把 `fn(a,b,c)` 变成 `curry(fn)(a)(b)(c)`，参数够了才执行。
```js
function curry(fn, ...args) {
  return (...next) => {
    const all = [...args, ...next];
    return all.length >= fn.length ? fn(...all) : curry(fn, ...all);
  };
}
```
**考察点**：闭包、函数 length（形参个数）、递归收集参数。　**易错点**：默认参数不计入 length，用 length 判断会提前执行；参数不足直接调 fn。

## 13. 数组乱序 shuffle
**题目**：Fisher-Yates 洗牌，保证每种排列概率相等。
```js
function shuffle(arr) {
  const a = arr.slice();
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));        // [0, i] 随机
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}
```
**考察点**：洗牌正确性、交换、随机数区间。　**易错点**：`sort(() => Math.random() - 0.5)` 不是等概率，要能说原因；随机区间写成 i-1 导致末尾概率异常。
## 14. 发布订阅 EventEmitter
**题目**：实现 on / off / once / emit，支持链式调用。
```js
class EventEmitter {
  constructor() { this.events = new Map(); }
  on(event, fn) { (this.events.get(event) || this.events.set(event, []).get(event)).push(fn); return this; }
  off(event, fn) { this.events.set(event, (this.events.get(event) || []).filter((f) => f !== fn)); return this; }
  once(event, fn) {
    const wrap = (...args) => { this.off(event, wrap); fn(...args); };
    return this.on(event, wrap);
  }
  emit(event, ...args) { (this.events.get(event) || []).slice().forEach((fn) => fn(...args)); return this; }
}
```
**考察点**：Map 存事件表、once 解绑、emit 遍历数组副本（允许回调里 off 自己）。　**易错点**：emit 直接遍历原数组时 off 导致跳过元素；once 里 off 包装函数而不是原函数。

## 17. 手写 map / filter
**题目**：实现 map 与 filter，支持 thisArg、跳过稀疏数组空位。
```js
Array.prototype.myMap = function (fn, thisArg) {
  const res = new Array(this.length);
  for (let i = 0; i < this.length; i++)
    if (i in this) res[i] = fn.call(thisArg, this[i], i, this);
  return res;
};
Array.prototype.myFilter = function (fn, thisArg) {
  const res = [];
  for (let i = 0; i < this.length; i++)
    if (i in this && fn.call(thisArg, this[i], i, this)) res.push(this[i]);
  return res;
};
```
**考察点**：thisArg 绑定、稀疏数组、map 长度不变而 filter 长度可变。　**易错点**：map 用 push 会丢空位；回调参数漏传 index。
## 18. 手写 JSON.stringify（基础版）
**题目**：支持 null/number/boolean/string/数组/普通对象，处理 toJSON 与不可序列化值。
```js
function jsonStringify(value) {
  if (value === null) return 'null';
  if (typeof value === 'number') return isFinite(value) ? String(value) : 'null';   // NaN/Infinity → null
  if (typeof value === 'boolean') return String(value);
  if (typeof value === 'string') return '"' + value.replace(/\\/g, '\\\\').replace(/"/g, '\\"').replace(/\n/g, '\\n') + '"';
  if (typeof value !== 'object') return undefined;        // undefined / function / symbol
  if (typeof value.toJSON === 'function') return jsonStringify(value.toJSON());
  if (Array.isArray(value)) return '[' + value.map((v) => jsonStringify(v) ?? 'null').join(',') + ']';
  return '{' + Object.keys(value).map((k) => {
    const s = jsonStringify(value[k]);
    return s === undefined ? null : `"${k}":${s}`;
  }).filter(Boolean).join(',') + '}';
}
```
**考察点**：类型分支、转义、toJSON、数组里 undefined 变 null、对象里 undefined 被丢弃。　**易错点**：忘记转义引号/反斜杠；Date 走 toJSON 变字符串；循环引用没检测。

## 20. LRU 缓存（Map 版）
**题目**：get/put 均为 O(1)，超出容量淘汰最久未使用的 key。
```js
class LRUCache {
  constructor(capacity) { this.capacity = capacity; this.map = new Map(); }
  get(key) {
    if (!this.map.has(key)) return -1;
    const val = this.map.get(key);
    this.map.delete(key); this.map.set(key, val);          // 删了重插 = 移到最新
    return val;
  }
  put(key, value) {
    if (this.map.has(key)) this.map.delete(key);
    this.map.set(key, value);
    if (this.map.size > this.capacity) this.map.delete(this.map.keys().next().value);   // 最旧的 key
  }
}
```
**考察点**：Map 保持插入顺序、keys().next() 取最旧、get 也要刷新顺序。　**易错点**：get 只取值不刷新顺序；容量判断用 `>=`；线上/高频场景用「哈希 + 双向链表」（LC 146）。
## 21. 深比较 deepEqual
**题目**：递归比较两个值，支持循环引用、Date、RegExp、数组。
```js
function deepEqual(a, b, seen = new WeakMap()) {
  if (Object.is(a, b)) return true;                       // 顺带处理 NaN
  if (typeof a !== 'object' || typeof b !== 'object' || !a || !b) return false;
  if (seen.get(a) === b) return true;                     // 循环引用
  seen.set(a, b);
  if (a instanceof Date) return a.getTime() === b.getTime();
  if (a instanceof RegExp) return String(a) === String(b);
  const ka = Reflect.ownKeys(a), kb = Reflect.ownKeys(b);
  if (ka.length !== kb.length) return false;
  return ka.every((k) => deepEqual(a[k], b[k], seen));
}
```
**考察点**：Object.is、类型判断、循环引用记录、Symbol 键。　**易错点**：用 `===` 比较 NaN；递归不记录已访问对象导致爆栈；数组与对象原型不同没比较。

## 24. 手写 ajax / fetch 封装
**题目**：封装请求：JSON 序列化、超时取消、HTTP 状态码与响应类型处理。
```js
async function request(url, { method = 'GET', body, headers = {}, timeout = 10000 } = {}) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), timeout);
  const options = { method, headers: { 'Content-Type': 'application/json', ...headers }, signal: controller.signal };
  if (body !== undefined && method !== 'GET') options.body = JSON.stringify(body);
  try {
    const res = await fetch(url, options);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
```

## 26. async 并发限制
**题目**：最多同时运行 limit 个任务，全部结束后按原顺序返回结果。
```js
async function asyncPool(limit, tasks) {
  const results = new Array(tasks.length);
  let next = 0;
  const worker = async () => {
    while (next < tasks.length) results[next] = await tasks[next++]();   // 先取下标再自增
  };
  await Promise.all(Array.from({ length: Math.min(limit, tasks.length) }, worker));
  return results;
}
```
**考察点**：并发池思想、闭包共享下标、结果保序、limit 大于任务数。　**易错点**：worker 只跑一次（没有 while）；下标自增写在 await 之后导致重复取任务；limit 为 0 死循环。
## 27. 千分位格式化
**题目**：把 1234567.89 格式化成 `1,234,567.89`。
```js
function formatMoney(num) {
  const [int, dec] = String(Math.abs(num)).split('.');
  const body = int.replace(/\B(?=(\d{3})+(?!\d))/g, ',');   // 每 3 位插逗号
  return (num < 0 ? '-' : '') + body + (dec ? `.${dec}` : '');
}
// 也可用 num.toLocaleString('en-US')；正则 \B 非单词边界 + 后面恰好 3n 位数字
```
**考察点**：正则前瞻、正负号、小数部分不插入、货币场景精度。　**易错点**：正则漏掉 `(?!\d)` 会在小数位乱插；负数拼接顺序错。
## 28. URL 参数解析
**题目**：解析 query string，支持重复 key 变数组、解码与 `+` 号。
```js
function parseQuery(url) {
  const idx = url.indexOf('?');
  if (idx === -1) return {};
  return url.slice(idx + 1).split('#')[0].split('&').reduce((acc, pair) => {
    if (!pair) return acc;
    const [k, v = ''] = pair.split('=');
    const key = decodeURIComponent(k), val = decodeURIComponent(v.replace(/\+/g, ' '));
    if (acc[key] === undefined) acc[key] = val;
    else acc[key] = [].concat(acc[key], val);
    return acc;
  }, {});
}
```
**考察点**：字符串分割、reduce 聚合、decodeURIComponent、重复 key。　**易错点**：不处理 `+` 号；不裁剪 hash；`split('=')` 后值里还有 `=` 会丢（用 indexOf 更稳）。
## 29. 手写 v-model（Vue3 组件版）
**题目**：实现组件上的 v-model：本质是 `modelValue` prop + `update:modelValue` 事件。
```js
import { defineComponent, h } from 'vue';
export default defineComponent({
  props: { modelValue: { type: String, default: '' } },
  emits: ['update:modelValue'],
  setup(props, { emit }) {
    return () => h('input', {
      value: props.modelValue,
      onInput: (e) => emit('update:modelValue', e.target.value),   // 子传父
    });
  },
});
// 父组件 <MyInput v-model="text" /> 展开为 :model-value + @update:model-value
```
**考察点**：单向数据流、props / emit、v-model 语法糖、多 v-model（`v-model:title`）。　**易错点**：子组件直接改 props（会警告）；emit 事件名 JS 里必须写 `update:modelValue`。
## 30. tap 装饰器 / 链式调用
**题目**：实现不改变值的 tap 和可链式调用的包装器。
```js
// tap：不改变值，只插入副作用，方便链式调试
const tap = (fn) => (value) => { fn(value); return value; };
class Chain {                                             // 每个方法返回 this 才能链式
  constructor(value) { this.value = value; }
  map(fn) { this.value = fn(this.value); return this; }
  tap(fn) { fn(this.value); return this; }
  end() { return this.value; }
}
// new Chain([1,2,3]).map((a) => a.filter((x) => x > 1)).map((a) => a.length).end() === 2
```
**考察点**：高阶函数、返回 this、链式 API 设计（jQuery / Lodash / 中间件都在用）。　**易错点**：map 里不 return this 导致链断；tap 直接返回 fn 的返回值。
