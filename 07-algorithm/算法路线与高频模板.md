## 1. 复杂度分析入门
- 大 O 只看最高阶、去常数：`3n² + 2n + 100` → `O(n²)`；`2n + 5` → `O(n)`。
- 量级排序：`O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)`。
- 空间：递归要算调用栈（DFS 空间 = 树高）；"原地"= O(1) 额外空间；哈希表通常 O(n)。
- **看数据范围反推算法**：`n ≤ 10⁵` 必须 O(n log n) 以内；`n ≤ 5000` 可 O(n²)；`n ≤ 20` 可状压/回溯；`n ≤ 10⁹` 基本是 O(log n) 的二分。

## 3. Java / JS 常用数据结构 API 对照
| 用途 | Java | JavaScript | 备注 |
|---|---|---|---|
| 动态数组 | `List<Integer> list = new ArrayList<>()` | `const arr = []` | `add/get/size` vs `push/arr[i]/length` |
| 哈希表 | `Map<Integer,Integer> m = new HashMap<>()` | `const map = new Map()` | Java 有 `getOrDefault` |

## 专题 1：数组与双指针
**适用题型**：有序数组找配对、原地删除/去重/移动、滑动窗口求最长最短。
**核心模板**：
```java
// ① 对撞指针（LC 167）
public int[] twoSum(int[] nums, int target) {
    int l = 0, r = nums.length - 1;
    while (l < r) {
        int s = nums[l] + nums[r];
        if (s == target) return new int[]{l + 1, r + 1};
        if (s < target) l++; else r--;
    }
    return new int[]{-1, -1};
}
// ② 滑动窗口：最长无重复子串（LC 3）
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> last = new HashMap<>();
    int left = 0, ans = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (last.getOrDefault(c, -1) >= left) left = last.get(c) + 1;
        last.put(c, right);
        ans = Math.max(ans, right - left + 1);
    }
    return ans;
}
```
**LeetCode 高频题**：
- **LC 26** 删除有序数组中的重复项：快慢指针原地覆盖 → O(n) / O(1)。
- **LC 167** 两数之和 II：有序数组对撞指针 → O(n) / O(1)。
- **LC 209** 长度最小的子数组：窗口和 ≥ target 就收缩左界 → O(n) / O(1)。

**易错点**：对撞写 `while (l < r)`，写成 `<=` 会自己撞自己；窗口收缩用 `while` 不是 `if`；快慢指针的 `slow` 语义是"下一个写入位置"。
## 专题 2：哈希表
**适用题型**：查重、配对求和、计数、字符统计、前缀和 + 哈希。
**核心模板**：
```java
// ① 两数之和（LC 1）：边遍历边查，先查后存
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> m = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        if (m.containsKey(target - nums[i])) return new int[]{m.get(target - nums[i]), i};
        m.put(nums[i], i);   // 顺序不能反，否则可能自己配自己
    }
    return new int[0];
}
// ② 字母异位词分组（LC 49）：排序后的字符串当 key
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> m = new HashMap<>();
    for (String s : strs) {
        char[] cs = s.toCharArray();
        Arrays.sort(cs);
        m.computeIfAbsent(new String(cs), k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(m.values());
}
```
**LeetCode 高频题**：
- **LC 242** 有效的字母异位词：`int[26]` 一个加一个减，最后全 0 → O(n) / O(1)。
- **LC 349** 两个数组的交集：两个 HashSet 求交 → O(n + m)。
- **LC 49** 字母异位词分组：排序后的串做 key → O(n·k log k)。

**易错点**：先查后存，否则 `[3,3], target=6` 会返回同一个下标；计数用 `int[26]` 比 HashMap 快一个量级；前缀和 + 哈希能解 **LC 560**（和为 K 的子数组）。
## 专题 3：链表
**适用题型**：反转、合并、判环、找中点、删除倒数第 N 个。
**核心模板**：
```java
// ① 反转链表（LC 206）
public ListNode reverseList(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;   // 先存 next，否则断链后找不到
        cur.next = prev; prev = cur; cur = next;
    }
    return prev;
}
// ② 合并两个有序链表（LC 21）：dummy 尾插
public ListNode mergeTwoLists(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = a != null ? a : b;
    return dummy.next;   // 返回 dummy.next，不是 dummy
}
```
**LeetCode 高频题**：
- **LC 206** 反转链表：三指针迭代 → O(n) / O(1)。
- **LC 21** 合并两个有序链表：dummy 尾插 → O(n + m) / O(1)。
- **LC 141 / 142** 环形链表 I / II：快慢指针相遇即有环，142 再走一次找入口 → O(n) / O(1)。

**易错点**：反转必须先存 `next`；快指针判空写 `fast != null && fast.next != null`；涉及删除头节点统一加 dummy。
## 专题 4：栈与队列（单调栈）
**适用题型**：括号匹配、逆波兰表达式、下一个更大元素、滑动窗口最大值、用栈实现队列。
**核心模板**：
```java
// ① 有效的括号（LC 20）
public boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') st.push(')');
        else if (c == '[') st.push(']');
        else if (c == '{') st.push('}');
        else if (st.isEmpty() || st.pop() != c) return false;
    }
    return st.isEmpty();
}
// ② 单调栈：每日温度（LC 739）—— 栈存下标，栈内温度递减
public int[] dailyTemperatures(int[] t) {
    int n = t.length, res[] = new int[n];
    Deque<Integer> st = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        while (!st.isEmpty() && t[i] > t[st.peek()]) {
            int j = st.pop();
            res[j] = i - j;
        }
        st.push(i);
    }
    return res;
}
```
**LeetCode 高频题**：
- **LC 20** 有效的括号：左括号入栈对应右括号，最后判空 → O(n) / O(n)。
- **LC 739** 每日温度：单调递减栈存下标，弹出时算距离 → O(n) / O(n)。
- **LC 239** 滑动窗口最大值：单调队列存下标，队头即最大值 → O(n) / O(k)。

**易错点**：单调栈存**下标**而不是值；`Deque` 的 `push/pop/peek` 是栈语义，`offer/poll` 是队列语义；用 `>` 还是 `>=` 取决于找严格更大还是包含相等。
## 专题 5：二叉树
**适用题型**：遍历、深度、路径、对称/翻转、最近公共祖先、BST 性质。
**核心模板**：
```java
// ① 递归遍历（LC 144；中/后序只挪 res.add 的位置）
public List<Integer> preorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    dfs(root, res);
    return res;
}
private void dfs(TreeNode node, List<Integer> res) {
    if (node == null) return;
    res.add(node.val);
    dfs(node.left, res); dfs(node.right, res);
}
// ② 中序遍历迭代版（LC 94）
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> st = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !st.isEmpty()) {
        while (cur != null) { st.push(cur); cur = cur.left; }
        cur = st.pop(); res.add(cur.val); cur = cur.right;
    }
    return res;
}
// ③ 层序遍历（LC 102）：队列 + 每层固定 size
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>(List.of(root));
    while (!q.isEmpty()) {
        int size = q.size();
        List<Integer> level = new ArrayList<>();
        while (size-- > 0) {
            TreeNode n = q.poll();
            level.add(n.val);
            if (n.left != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
        res.add(level);
    }
    return res;
}
```
**LeetCode 高频题**：
- **LC 94** 二叉树的中序遍历：递归 / 迭代两版都要会 → O(n) / O(n)。
- **LC 102** 二叉树的层序遍历：BFS 逐层收集 → O(n) / O(n)。
- **LC 226 / 236** 翻转二叉树 / 最近公共祖先：递归交换左右、后序找 LCA → O(n)。

**易错点**：层序里 `q.size()` 一定要先存下来；空树提前返回；递归返回值语义要固定（返回"深度"还是"找到的节点"）。
## 专题 6：DFS / BFS（图与网格）
**适用题型**：岛屿数量、连通块、矩阵最短路径、腐烂橘子。
**核心模板**：
```java
// ① 网格 DFS：岛屿数量（LC 200）—— 访问过就淹掉，省 visited 数组
public int numIslands(char[][] grid) {
    int count = 0;
    for (int i = 0; i < grid.length; i++)
        for (int j = 0; j < grid[0].length; j++)
            if (grid[i][j] == '1') { count++; dfs(grid, i, j); }
    return count;
}
private void dfs(char[][] g, int i, int j) {
    if (i < 0 || i >= g.length || j < 0 || j >= g[0].length || g[i][j] != '1') return;
    g[i][j] = '0';   // 标记已访问
    dfs(g, i + 1, j); dfs(g, i - 1, j); dfs(g, i, j + 1); dfs(g, i, j - 1);
}
// ② 网格 BFS：求最短步数，多源起点全部先入队
private static final int[][] DIRS = {{1,0},{-1,0},{0,1},{0,-1}};
public int minSteps(char[][] grid) {
    int m = grid.length, n = grid[0].length, steps = 0;
    Queue<int[]> q = new LinkedList<>(); q.offer(new int[]{0, 0}); grid[0][0] = '#';
    while (!q.isEmpty()) {
        int size = q.size();
        while (size-- > 0) {
            int[] p = q.poll();
            if (p[0] == m - 1 && p[1] == n - 1) return steps;
            for (int[] d : DIRS) {
                int x = p[0] + d[0], y = p[1] + d[1];
                if (x < 0 || x >= m || y < 0 || y >= n || grid[x][y] == '#') continue;
                grid[x][y] = '#'; q.offer(new int[]{x, y});   // 入队即标记
            }
        }
        steps++;
    }
    return -1;
}
```
**LeetCode 高频题**：
- **LC 200** 岛屿数量：DFS/BFS 淹岛 → O(m·n) / O(m·n)。
- **LC 695** 岛屿的最大面积：DFS 返回 `1 + 四周面积` → O(m·n)。
- **LC 994 / 542** 腐烂的橘子 / 01 矩阵：多源 BFS 逐层扩散 → O(m·n)。

**易错点**：DFS 先判空再越界；BFS 必须**入队时标记**，出队才标记会重复入队直接超时；求"最少步数"一律 BFS，别用 DFS。
## 专题 7：回溯（组合 / 排列 / 子集）
**适用题型**：组合、排列、子集、分割、棋盘问题（N 皇后）。
**核心模板**：
```java
// ① 排列（LC 46）：顺序有关，用 used 数组
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}
private void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }  // 必须拷贝
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true; path.add(nums[i]);
        backtrack(nums, used, path, res);
        path.remove(path.size() - 1); used[i] = false;   // 撤销选择
    }
}
// ② 子集（LC 78）：顺序无关用 start；组合总和（LC 39）把 i+1 改成 i
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, 0, new ArrayList<>(), res);
    return res;
}
private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));   // 每个节点都是一个子集
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        dfs(nums, i + 1, path, res);
        path.remove(path.size() - 1);
    }
}
```
**LeetCode 高频题**：
- **LC 46** 全排列：used 标记 + 撤销选择 → O(n·n!)。
- **LC 78** 子集：`start` 控制不回头，每个节点都收集 → O(n·2ⁿ)。
- **LC 39** 组合总和：元素可复用，下一层传 `i` 而不是 `i+1` → 指数级。

**易错点**：`res.add(path)` 只存引用，必须 `new ArrayList<>(path)`；选择与撤销必须严格对称；有重复元素先排序，再用 `i > 0 && nums[i] == nums[i-1] && !used[i-1]` 去重。
## 专题 8：动态规划
**适用题型**：最值（最大子数组和、最长递增子序列）、计数（爬楼梯、路径数）、可行性（能否凑成目标）。
**核心模板**：
```java
// ① 爬楼梯（LC 70）：滚动变量，空间 O(1)
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;   // a=dp[i-2], b=dp[i-1]
    for (int i = 3; i <= n; i++) { int c = a + b; a = b; b = c; }
    return b;
}
// ② 打家劫舍（LC 198）：选或不选
public int rob(int[] nums) {
    int prev = 0, cur = 0;   // prev=dp[i-2], cur=dp[i-1]
    for (int x : nums) { int next = Math.max(cur, prev + x); prev = cur; cur = next; }
    return cur;
}
// ③ 最长递增子序列（LC 300）：O(n²) 版，面试先写这个
public int lengthOfLIS(int[] nums) {
    int n = nums.length, ans = 0, dp[] = new int[n];
    for (int i = 0; i < n; i++) {
        dp[i] = 1;
        for (int j = 0; j < i; j++)
            if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
        ans = Math.max(ans, dp[i]);
    }
    return ans;
}
```
**LeetCode 高频题**：
- **LC 70** 爬楼梯：`f(n) = f(n-1) + f(n-2)` → O(n) / O(1)。
- **LC 198** 打家劫舍：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])` → O(n) / O(1)。
- **LC 300** 最长递增子序列：`dp[i] = max(dp[j]) + 1` → O(n²) / O(n)。

**易错点**：`dp` 数组长度是 `n` 还是 `n+1` 要想清楚；求最小初始化用 `amount+1` 而不是 `Integer.MAX_VALUE`（防溢出）；01 背包一维倒序、完全背包正序；状态定义写清"以 i 结尾"还是"前 i 个"。
## 专题 9：二分查找
**适用题型**：有序数组查找、第一个/最后一个位置、旋转数组、答案二分（"最小值最大化"）。
**核心模板**：
```java
// ① 标准二分（LC 704）：闭区间 [l, r]
public int search(int[] nums, int target) {
    int l = 0, r = nums.length - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;   // 防溢出，别写 (l+r)/2
        if (nums[mid] == target) return mid;
        if (nums[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
// ② 找左边界（LC 34 的一半）：第一个 >= target 的位置，区间 [l, r)
public int lowerBound(int[] nums, int target) {
    int l = 0, r = nums.length;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] < target) l = mid + 1;
        else r = mid;   // 不排除 mid，它可能就是答案
    }
    return l;   // l == r，即插入位置
}
```
**LeetCode 高频题**：
- **LC 704** 二分查找：闭区间写法 → O(log n) / O(1)。
- **LC 34** 查找第一个和最后一个位置：`lowerBound(t)` 与 `lowerBound(t+1)-1` → O(log n)。
- **LC 33** 搜索旋转排序数组：判断哪半边有序再二分 → O(log n)。

**易错点**：`mid = l + (r - l) / 2` 防溢出；区间不变量要自洽（闭区间配 `l=mid+1/r=mid-1`，左闭右开配 `l=mid+1/r=mid`）；`while (l <= r)` 与 `while (l < r)` 混用会死循环或漏答案。
## 专题 10：排序（手写快排 / 归并）
**适用题型**：手写排序、第 K 大、逆序对、合并两个有序数组。
**核心模板**：
```java
// ① 快速排序：pivot 取中间值，防有序数组退化
public void quickSort(int[] a, int l, int r) {
    if (l >= r) return;
    int pivot = a[(l + r) >>> 1];
    int i = l, j = r;
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) { int t = a[i]; a[i] = a[j]; a[j] = t; i++; j--; }
    }
    quickSort(a, l, j);
    quickSort(a, i, r);
}
// ② 归并排序：稳定，O(n log n)，需要临时数组
public void mergeSort(int[] a, int l, int r, int[] tmp) {
    if (l >= r) return;
    int mid = (l + r) >>> 1;
    mergeSort(a, l, mid, tmp);
    mergeSort(a, mid + 1, r, tmp);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];   // <= 才稳定
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int x = l; x <= r; x++) a[x] = tmp[x];
}
```
**LeetCode 高频题**：
- **LC 912** 排序数组：快排 / 归并任选手写 → O(n log n)。
- **LC 215** 数组中的第 K 个最大元素：小顶堆维持 k 个，或 partition 只递归一侧 → O(n) / O(n log k)。
- **LC 148** 排序链表：归并排序（快慢指针找中点 + 合并）→ O(n log n) / O(1)。

**易错点**：快排内层用 `while (i <= j)`；pivot 取首元素遇到有序数组会退化成 O(n²)；归并合并用 `<=` 才稳定；递归终止写 `l >= r`。
## 专题 11：贪心入门
**适用题型**：跳跃游戏、买卖股票、区间调度、分发饼干。
**核心模板**：
```java
// ① 跳跃游戏（LC 55）：维护能到达的最远下标
public boolean canJump(int[] nums) {
    int farthest = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > farthest) return false;   // 当前位置都到不了
        farthest = Math.max(farthest, i + nums[i]);
    }
    return true;
}
```
**LeetCode 高频题**：
- **LC 55** 跳跃游戏：维护最远可达位置 → O(n) / O(1)。
- **LC 122** 买卖股票的最佳时机 II：累加所有正收益 → O(n) / O(1)。
- **LC 435** 无重叠区间：按右端点升序排序后能选就选 → O(n log n)。

**易错点**：贪心不是"看着对就行"，面试要能说清为什么局部最优能推出全局最优；区间问题排序字段选错（左端还是右端）直接错；想不出贪心就用 DP 兜底。
