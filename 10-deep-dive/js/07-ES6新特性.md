# ES6+ 新特性（ES6+ Features）

> 面试权重：4/5　｜　追问深度：**L5（TDZ 的 the_hole + 迭代器协议 + Proxy 陷阱）**
> 一句话定位：ES6 不是"加了几个语法糖"，它补上了**块级作用域、迭代协议、元编程（Proxy/Reflect）和模块系统**四块地基；Vue3 的响应式就建在 Proxy 上。

**本文件用法**：语法层大家都会用，面试拉开差距的是 L3：TDZ 怎么实现、for...of 为什么能 break、Proxy 为什么有"不变式"。**术语表要能逐条拆开。**
[返回深度追问索引](../00-索引.md)

## L1 一句话答案（10 秒能说出口）

ES6+ 的核心是四件事：`let/const` 提供块级作用域与 TDZ；解构/展开/箭头函数/模板字符串提升表达力；`Symbol` + 迭代器协议让对象可被 `for...of`/展开；`Proxy/Reflect` 提供元编程能力（Vue3 响应式基础），外加 Promise 与 ESM 模块。

---

## L2 原理层：按能力分组的高频特性

| 能力 | 特性 | 解决什么问题 |
|---|---|---|
| 作用域 | `let/const` + TDZ | `var` 变量提升、循环共享绑定、全局污染 |
| 表达式 | 解构、默认参数、剩余/展开、模板字符串 | 取值/合并/拼接代码冗长 |
| 函数 | 箭头函数、`this` 词法化 | 回调里 this 丢失 |
| 对象/类 | 属性简写、计算属性、`class`、`super` | 手写原型的样板代码 |
| 异步 | `Promise`、`async/await` | 回调地狱（见 [async/await](./03-async-await.md)） |
| 元编程 | `Symbol`、迭代器/生成器、`Proxy/Reflect` | 可自定义语言行为、响应式拦截 |
| 模块 | ESM：`import/export`、动态 `import()` | 全局脚本、CJS 的动态性 |
| 现代语法 | 可选链 `?.`、空值合并 `??`（ES2020） | 深层取值与 `0/''` 误判 |

```js
// 解构默认值：只有 undefined 才触发默认值，null 不会
const { a = 1, b = 2 } = { a: undefined, b: null }
console.log(a, b) // 1 null

// 可选链 + 空值合并
const user = { profile: null, age: 0 }
console.log(user?.profile?.name ?? '匿名') // 匿名
console.log(user.age ?? 18) // 0（用 || 会得到 18）
```

**`class` 不是新继承模型**：它是构造函数 + 原型链的语法糖，区别是方法不可枚举、默认严格模式、必须 `new`、`super()` 有 TDZ 约束。详见 [原型链](./01-原型链.md)。

## L3 底层层：TDZ、迭代器、Proxy 三块硬骨头

### 3.1 `let/const` 与 TDZ 的真实实现

- 编译期：`let/const` 变量被登记进**词法环境**，但初始值是 V8 内部的 `the_hole` 哨兵值（"未初始化"标记），而不是 `undefined`。
- 访问 TDZ 变量时，V8 检查到 `the_hole` → 抛 `ReferenceError: Cannot access 'x' before initialization`；`typeof` 也会抛（和未声明变量不同）。
- `const` 的"常量"指**绑定不可重新赋值**，不是值不可变：`const obj = {}` 仍可 `obj.a = 1`；要冻结用 `Object.freeze`（浅冻结）。
- 降级到 ES5 时，Babel 用 `var` + 重命名模拟块级作用域，但**无法完全模拟 TDZ**，只能靠运行时代码检查，所以降级产物的报错行为可能和原生不同。

### 3.2 迭代器协议：`for...of` 到底怎么展开

1. 取 `obj[Symbol.iterator]`，必须是函数，调用后返回**迭代器**；
2. 每次循环调 `iterator.next()`，拿到 `{ value, done }`；
3. `done: true` 停止；
4. **提前退出（`break`/`return`/抛错）时，调用 `iterator.return()`** 做资源清理——这是 `for await` 能正确关闭流的关键。

展开运算符、数组解构、`Array.from`、`Map/Set` 构造、`yield*` 全部基于这个协议。手写实现见 [async/await](./03-async-await.md) 的异步迭代器部分。

### 3.3 Proxy 的 13 个 trap 与"不变式"

| trap | 拦截的操作 |
|---|---|
| `get` | 读属性 |
| `set` | 写属性 |
| `has` | `in` |
| `deleteProperty` | `delete` |
| `ownKeys` | `Object.keys`、`for...in`、`JSON.stringify` |
| `getOwnPropertyDescriptor` | `Object.getOwnPropertyDescriptor` |
| `defineProperty` | `Object.defineProperty` |
| `getPrototypeOf` | `Object.getPrototypeOf` |
| `setPrototypeOf` | `Object.setPrototypeOf` |
| `isExtensible` | `Object.isExtensible` |
| `preventExtensions` | `Object.preventExtensions` |
| `apply` | 函数调用 |
| `construct` | `new` |

**代理不变式（invariant）**：Proxy 不能撒谎到破坏对象模型。例如目标对象有不可配置属性时，`ownKeys` 必须返回它；不可写不可配置属性的 `get` 必须返回真实值。违反会抛 `TypeError`。

**Vue3 为什么用 Proxy 替代 `defineProperty`**：`defineProperty` 只能劫持已存在的属性，新增/删除属性、数组索引、`Map/Set` 都要打补丁；Proxy 拦截整个对象，配合 `Reflect` 保持默认行为，还能懒代理嵌套对象。

### 3.4 ESM 与 CJS 的本质区别

| 维度 | ESM | CJS |
|---|---|---|
| 加载时机 | 静态解析、编译期确定依赖 | 运行时 `require` 动态加载 |
| 绑定 | **live binding**（导出变量变化，导入方可见） | 值拷贝 |
| 循环依赖 | 有 TDZ 的暂时死区处理 | 返回未完成的 exports 对象 |
| Tree-shaking | 支持（静态结构可分析） | 基本不支持 |
| 顶层 await | 支持（ES2022） | 不支持 |

`import()` 动态导入返回 Promise，是路由懒加载和 Vite 代码分割的入口。

## L4 追问树（面试官一路往下问，你能撑到第几层？）

> 规则：从上往下问。**第 1-3 层必备，第 4-6 层拉开差距，第 7 层以后加分。**

### 第 1 层｜`let`、`const`、`var` 的区别？
**答**：`var` 函数作用域、提升并初始化为 undefined、可重复声明；`let/const` 块级作用域、TDZ、不可重复声明；`const` 绑定不可重新赋值但对象可改。

### 第 2 层｜TDZ 是什么？为什么需要它？
**答**：从块开始到声明语句之间的"未初始化"区间；它让 `let/const` 的声明前访问直接报错，避免 `var` 那种"先用后声明"的隐蔽 bug，也让 `const` 语义更严格。

### 第 3 层｜`const` 声明的对象能改吗？
**答**：能改属性，不能重新赋值。`const` 约束的是绑定，不是对象内部状态；要不可变用 `Object.freeze`（且只是浅冻结）。

### 第 4 层｜解构默认值什么时候生效？
**答**：只有属性值为 `undefined` 时生效；`null` 不触发默认值，`0`/`''`/`false` 也不触发。函数参数解构同理。

### 第 5 层｜`for...of` 和 `for...in` 的区别？
**答**：`for...of` 走迭代器协议，遍历值，适用于数组/Map/Set/字符串/自定义可迭代对象；`for...in` 遍历可枚举属性名（含原型链），适合对象但要 `hasOwnProperty` 过滤。

### 第 6 层｜`for...of` 中途 `break` 会发生什么？
**答**：引擎会调用迭代器的 `return()` 方法做清理（关闭流、释放资源）；所以自定义迭代器要实现 `return`，否则资源可能泄漏。

### 第 7 层｜`Symbol` 有什么用？
**答**：① 唯一键，避免属性名冲突（库内部标记）；② 定义语言协议：`Symbol.iterator`、`Symbol.asyncIterator`、`Symbol.toPrimitive`、`Symbol.hasInstance`；③ `Symbol.for` 全局注册表可跨模块共享。

### 第 8 层｜Proxy 和 `Object.defineProperty` 的区别？
**答**：`defineProperty` 劫持单个已存在属性，新增/删除/数组索引要额外处理；Proxy 代理整个对象，可拦截 13 种操作，新增属性、删除、`in`、`Object.keys` 都能拦；Vue3 因此换成 Proxy。

### 第 9 层｜Proxy 的代理不变式是什么？为什么要限制？
**答**：规范要求 Proxy 的行为不能与目标对象的不可配置/不可写属性矛盾，例如 `ownKeys` 不能漏掉不可配置属性、`get` 对不可写不可配置属性必须返回真实值；否则对象模型会自相矛盾，语言无法保证一致性，所以直接抛 TypeError。

### 第 10 层（终局）｜V8 里 TDZ、迭代器、Proxy 分别怎么落地？
**答**：TDZ 用 `the_hole` 哨兵值标记未初始化，读取时检查抛错；迭代器调用走 `GetIterator`/`IteratorNext`/`IteratorClose` 内建，`for...of` 被编译成显式协议调用（含 try/finally 触发 `return`）；Proxy 创建异质对象 `JSProxy`，内部持有 target 和 handler，所有操作走 trap 查找，未定义 trap 时回落到 target 的默认内部方法——Vue3 的响应式就是在这个入口上收集依赖。

## L5 名词拆解表（"每个名词都拆开"）

| 名词 | 是什么 | 为什么存在 | 面试追问点 |
|---|---|---|---|
| TDZ | 声明前不可访问的区间 | 避免先用后声明 | 为什么 `typeof` 也抛 |
| `the_hole` | V8 的"未初始化"哨兵值 | 区分未初始化与 undefined | 与 `undefined` 的差别 |
| 词法环境 | 块级变量存储结构 | 支撑 let/const 作用域 | 与变量环境的区别 |
| 迭代器协议 | `next()` 返回 `{value, done}` | 统一遍历各种数据结构 | 手写一个迭代器 |
| 可迭代对象 | 实现 `[Symbol.iterator]` 的对象 | 让 `for...of`/展开可用 | 数组/Map/Set 都实现了 |
| `Symbol.iterator` | 迭代器工厂的键 | 语言层面的协议入口 | 与 `Symbol.asyncIterator` 区别 |
| `IteratorClose` | 提前退出时的清理流程 | `break`/抛错时释放资源 | 为什么自定义迭代器要写 return |
| Proxy trap | 拦截对象操作的钩子 | 元编程、响应式 | 13 个 trap 各拦什么 |
| 代理不变式 | Proxy 必须遵守的约束 | 保证对象模型一致性 | 违反会怎样 |
| Reflect | 内部方法的函数式包装 | 让默认行为可被复用 | 为什么 Vue3 用 Reflect |
| live binding | ESM 导入的是活的绑定 | 导出值变化能同步 | 与 CJS 值拷贝区别 |
| Tree-shaking | 静态分析删除未用代码 | 减小打包体积 | 为什么 CJS 不行 |
| 可选链 `?.` | 空值安全访问 | 深层取值不报错 | 短路范围 |
| 空值合并 `??` | 只对 null/undefined 兜底 | 保留 0/''/false | 与 `||` 区别 |

## 代码验证（打开浏览器控制台逐条跑，验证理解）

```js
// 1. TDZ
try { console.log(x) } catch (e) { console.log('TDZ', e.message) } // ReferenceError
let x = 1
// typeof TDZ 变量也会抛（与未声明变量不同）
try { typeof y; let y = 1 } catch (e) { console.log('typeof TDZ', e.constructor.name) } // ReferenceError

// 2. 解构默认值只认 undefined
const { a = '默认', b = '默认', c = '默认' } = { a: undefined, b: null, c: 0 }
console.log(a, b, c) // 默认 null 0

// 3. 自定义迭代器 + for...of 提前退出会调用 return
const iterable = {
  [Symbol.iterator]() {
    let i = 0
    return {
      next: () => (i < 3 ? { value: i++, done: false } : { value: undefined, done: true }),
      return: () => { console.log('清理：return 被调用'); return { done: true } },
    }
  },
}
for (const v of iterable) {
  if (v === 1) break // 触发 iterator.return()
}
console.log([...iterable]) // [0, 1, 2]（展开会走完整迭代）

// 4. Proxy：拦截 get/set/has/ownKeys
const raw = { name: 'vue', age: 3 }
const logged = new Proxy(raw, {
  get(target, key, receiver) {
    console.log('get', String(key))
    return Reflect.get(target, key, receiver)
  },
  set(target, key, value, receiver) {
    console.log('set', String(key), value)
    return Reflect.set(target, key, value, receiver)
  },
  has(target, key) { console.log('has', String(key)); return Reflect.has(target, key) },
  ownKeys(target) { console.log('ownKeys'); return Reflect.ownKeys(target) },
})
console.log(logged.name) // get name → vue
logged.age = 4 // set age 4
console.log('age' in logged) // has age → true
console.log(Object.keys(logged)) // ownKeys → ['name', 'age']

// 5. 代理不变式：不可配置属性不能从 ownKeys 里漏掉
const frozen = Object.defineProperty({}, 'x', { value: 1, configurable: false, enumerable: true })
const bad = new Proxy(frozen, { ownKeys: () => [] })
try { Object.keys(bad) } catch (e) { console.log('不变式', e.constructor.name) } // TypeError

// 6. 可选链 + 空值合并
const resp = { data: null, count: 0 }
console.log(resp.data?.items?.[0] ?? '无数据') // 无数据
console.log(resp.count ?? 10) // 0
```

## 高频错误（面试官最爱抓的）

| 错误说法 | 正确说法 |
|---|---|
| 「`const` 声明的对象不能修改」 | 不能重新赋值，属性可改 |
| 「`let` 没有提升」 | 提升但处于 TDZ，访问报错 |
| 「解构默认值对 `null` 也生效」 | 只对 `undefined` 生效 |
| 「`for...of` 遍历属性名」 | 遍历值，`for...in` 才遍历键 |
| 「Proxy 可以随意改写对象行为」 | 受代理不变式约束 |
| 「ESM 和 CJS 只是写法不同」 | 静态 vs 动态、live binding、tree-shaking 都不同 |
