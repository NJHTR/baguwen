# 精讲索引（教材式）

> 这一层的定位：**不是速查，是教材。**
> 每个知识点从「零基础能看懂」讲到「源码级」，把每个名词都拆开，每个「为什么」都给出被否决的替代方案。
> 写作样板：[HashMap 的 hash() 为什么要做高低 16 位异或扰动](./java/01-HashMap-hash扰动.md)

---

## 一、和深度追问层的区别

| | 深度追问层（10-deep-dive） | 精讲层（11-lectures，本目录） |
|---|---|---|
| 定位 | 面试速查 + 追问树 | 教材，从原理讲到源码 |
| 篇幅 | 200-300 行 | 450-600 行 |
| 结构 | L1 一句话 → L5 名词表 | 痛点 → 推导 → 极简模型 → 设计取舍 → 版本差异 → 验证 → 误区 → Q&A |
| 什么时候看 | 面试前 1 天、被追问时 | 第一遍学明白、面试前两周 |
| 读法 | 跳着看 | 从头到尾，边读边跑代码 |

**推荐顺序：先精讲（学懂为什么）→ 再速查（记住怎么答）→ 最后模拟面试（说出来）。**

---

## 二、每篇的固定结构（15 节）

```
0. 一句话先讲明白
1. 它解决什么问题（先讲痛点，不讲定义）
2. 一步步拆开（源码逐行 + 二进制/内存图示）
3. 完整推导（把「为什么有效」算出来）
4. 极简模型（缩小规模帮助理解）
5. 为什么这样设计（≥4 个被否决的替代方案）
6. 关键参数为什么是这个值
7. 版本演进
8. 亲手验证（可运行代码/命令 + 预期输出）
9. 常见误区（8 行左右）
10. 连续追问 Q&A（10-14 问）
11. 一张图总结
12. 一句话复盘
13. 自测题（5-7 题带答案）
14. 关联文件
```

## 四、怎么读一篇精讲

1. **先看第 0 节和第 12 节**（一句话 + 复盘），知道要讲什么
2. **从头读第 1 到 5 节**，遇到不懂的名词停下，它一定在第 1 次出现时被解释过
3. **跑第 8 节的代码**，把输出和第 3 节的推导对上
4. **做第 13 节的自测题**，答不出回到对应小节
5. **用第 10 节的 Q&A 自问自答**，能答上来才算真的懂
